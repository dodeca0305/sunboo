# 法人税の中間申告：確認する書類の案内

2026-11-10。利用者の「中間申告も、どの書類のどこを見れば確認できるか案内がほしい」に対応。直前の試用項目である法人税の中間申告へ、管理用/ローカル保存用で共用する「どこを見る？」を追加する。消費税の回数案内は今回追加しない。

## 案内

今回登録する決算期の確定申告書「別表一」にある「中間申告分の法人税額」を見本上の枠で示す。納付すべき金額の欄であり、納付済みかどうかとは別であることを明記。空欄・0・書類なしで判断できない場合には、それだけで「なし」と決めず、中間申告書の控えなどを税理士と確認し、不明なまま保存しないよう案内する。

根拠は国税庁の[申告書作成上の留意点・別表一](https://www.nta.go.jp/publication/pamph/hojin/aramashi2024/pdf/02.pdf)の記載。中間申告分は納付の有無にかかわらず記載する旨を確認した。見本は既存の[令和7年・別表一](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/shinkoku/itiran2025/pdf/01-01-a.pdf)の空様式画像を再利用する。左3.4%・上65.5%・幅46.8%・高さ2%の対象行をCSSで示す。年度差を明記し、欄番号の一律指定や金額からの自動判定はしない。
