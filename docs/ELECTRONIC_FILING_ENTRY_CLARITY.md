# 電子手続きの入口（2026-11-07）

基点main c598b88 / PR #175。試用結果の優先順位4「電子申告の入口が分からない」に対応。既存の電子手続き名/URLを利用し、DBやマスターを更新しない。

管理・共有・一般の年間ロードマップと一般診断結果に、同じ「オンラインで進める」枠を表示する。カードの手続き名の直後（一般診断では提出先の注意に続く位置）に置き、提出先の公式説明・様式と入口を区別する。

- 登録されたe-Taxには、法人向けの利用案内と法人ログインを別ボタンで表示。WEB版で全ての申告書を作成できるとは説明しない。
- 登録されたeLTAXには、現在の地方税共同機構のPCdesk/PCdesk Next案内へ進むボタンを表示。税目と内容に合うソフトを公式案内で確認し、WEB版だけで全て申告できるとは説明しない。
- 税目コード・登録システム名・既存の公式HTTPSトップURLが一致する確認済みの組み合わせだけにリンクを出す。国税/地方税の不一致・不明なコード・HTTP/偽装ホスト/資格情報付き/クエリ付き/不正URLには入口を推測しない。
- 正常な未登録は「未登録」、不正/不完全な登録は「確認できません」とし、提出先の公式案内で確認する。税務の該当判定・表示する手続き・期限・金額は変えない。
- 国税/地方税以外の電子手続きの入口改善は対象外。既存の一般診断のそれらのリンク表示は維持する。
- SUNBOOから申告送信・支払いはしない。公式サイトは別タブで開き、提出先/必要な準備を確認して進む。郵送/窓口等の既存案内も残す。
