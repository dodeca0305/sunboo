# 共有リンク一覧の取得失敗と発行結果不明時の保護（2026-10-31）

## 問題と変更

- 最新mainのPR #140反映後を起点に修正。作業途中の未追跡ファイルはコピーを保護し、変更対象へ含めない。
- 一覧の取得失敗（error/null/通信例外）と、正常なリンク0件を区別する。失敗時はエラーと再読み込みリンクを表示し、0件とは表示しない。一覧取得とブラウザ内の前回要求の復元が成功するまで新規発行を停止する。
- 発行前に暗号学的乱数32バイトのトークンと会社ID・発行者・期限をsessionStorageへ保存。再読み込み後も同じ要求を維持する。保存できなければINSERTしない。
- 不明な結果を「未発行」と決めつけない。新しい要求は停止し、専用ボタンで同じトークンを照会・再試行する。照会に失敗した場合はINSERTしない。
- 同じトークンでのみINSERTするため、先行要求の確定が遅れても既存のUNIQUE制約で二重作成しない。既存行が見つかったらその行を表示し、失効・期限を変更するupsertは使わない。
- 結果確認後に保存済み要求を解除する。確認中は期限を変えず、同一イベント内の連打もrefのロックで止める。
- DBのトークン一意インデックスを読み取り確認済み。DBスキーマ・権限の変更なし。
