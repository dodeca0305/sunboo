# 会社ホームの「最初の一歩」

会社見出しの直後に、短い説明と大きい黒ボタン1つを置く。新機能・判定・保存は変更しない。
選択は `src/lib/workspaceFirstStep.ts` の純粋関数 `selectWorkspaceFirstStep` だけで行う。

| 順 | 状態 | 表示 | ボタン |
| --- | --- | --- | --- |
| 1 | 必要な読取が失敗 | 「必要な情報を取得できません」。次の行動は決めない | 既存の再読み込みのみ |
| 2 | 既存todayActions先頭がhigh | その1件（既存順） | 急ぐ対応を開く |
| 3 | 必須案内項目が未入力 | 「まず、会社情報を入力してください」 | 入力を始める（既存missingProfileInputs先頭の入力欄へ） |
| 4 | 入力済みでtodayActionsあり | 既存先頭1件 | 対応を開く（既存actionHref/手続き深いリンク） |
| 5 | 候補0件 | 今後の手続きを確認する案内（対応不要とは言わない） | ロードマップを見る |

- 2のとき、未入力の案内カード（home-missing-profile）は残す。3のときだけ、同カード内の重複リンクを出さない。
- 税務・期限の再判定、新しい優先順位は持たない。残りの今日やること/警告/期限/税務概要/部分取得表示は従来どおり。
- ボタンは共通の `btn-primary`（オレンジ）に、このボタンだけ既存トークン `bg-sunboo-ink` を当てて黒にした。共通色は変更していない。
- 取得失敗時の再読み込みは最上部の1つに集約（従来のalert内ボタンは削除。本文は維持）。
