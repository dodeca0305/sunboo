# 消費税の中間申告回数を確認する案内

2026-11-10。中間申告の確認元を案内する要望と、法人税の対応後の「行こう」を受け、管理用/ローカル保存用の消費税中間申告回数へ「どこを見る？」を追加する。

## 案内と根拠

確認方法は「中間申告書の控えを見る」「e-Taxの記録を見る」の2つ。控えでは、この決算期に対応する中間申告対象期間の欄を見本で示し、同じ期間の再送・修正を重複して数えないよう案内する。仮決算などでは様式が異なることを明記。e-Taxは、お知らせ・受信通知から対象の申告記録と対象期間を確認するための公式説明へリンクする。外部サービスへのログイン・申告作成・納付はSUNBOOから行わない。

- [国税庁・中間申告書の空様式](https://www.nta.go.jp/law/tsutatsu/kobetsu/kansetsu/951225/pdf/youshiki_036.pdf)
- [e-Tax・申告データの表示/印刷方法](https://www.e-tax.nta.go.jp/toiawase/qa/e-taxweb/43.htm)
- [国税庁No.9211・申告書等の確認方法](https://www.nta.go.jp/taxes/shiraberu/taxanswer/osirase/9211.htm)
- [国税庁・法人へのお知らせの格納](https://www.e-tax.nta.go.jp/topics/2025/topics_20250106_messagebox_jiki.htm)
- [国税庁No.6609・みなし申告等](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6609.htm)

年税額からの回数区分や確定申告書の中間納付額を、その決算期の実績回数として自動推定しない。お知らせの件数を提出済みの回数とは扱わず、申告書や受信通知がない場合も「なし」と決めない。みなし申告、記録不足、選択肢に合わない場合は税理士への確認と保存保留を案内する。これは案内文であり、既存の保存制御に新しい条件を追加したものではない。

public/guides/consumption-tax-interim.pngは、国税庁の予定申告用の空様式を高さ1500で描画した上部1061×740の見本。左71.3%・上58.4%・幅27%・高さ13.7%の対象期間欄をCSSで示す。原本・画像・枠の位置・文言は様式更新時にセットで確認する。顧客の書類や金額を含まない。

## 検証と変更範囲

合成試験で両画面、375px、控え/ e-Taxの開閉、画像と公式リンク、4つの選択値の保持、案内で書込回数が増えないことを確認。既存の税額/法人税中間案内、期間入力、0/null・既存表記、年度不一致、短期決算、取得失敗/復旧、保存拒否/応答喪失後の再取得も成功。合成書込3、本番呼出/ブラウザー例外0。Lintエラー0/既存警告1。最終ビルド・CI・配信結果はBusiness側へ追記する。本番は架空会社23の閲覧と案内開閉のみ。

回数選択に名前を付けて操作しやすくしたが、選択肢・初期値・onChange・保存・税務判定/期限計算は変更しない。「未確認」の保存値は追加しない。DB/関数/権限/課金変更なし。復旧はアプリの表示変更を戻して通常配信、DB作業不要。
