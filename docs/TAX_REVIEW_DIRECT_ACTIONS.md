# 税金の確認結果：実際の入力欄へ直接進む

2026-11-08。main 85e2875（PR #179）・点検記録・オープンPR 0件を確認して着手。

利用者は選択式の「見た目・何を選ぶか・選択後の内容」をすべて改善対象と評価。「具体的なやることと入力欄へ進むボタン」を中心に見直す案へ「お願いします」と回答。PR #178で肯定された初期表示・配色は残し、PR #179の抽象的な行動選択欄を取り除く。

## 表示と根拠

新規チェックの詳細を開いたら、現在のプロフィールと決算実績を既存の厳格な読み取り処理で取得して、次の入力案内を1つ表示する。税務評価は実行しない。

- 正常取得した会社の決算月がnull：既存のプロフィールの決算月欄へ。一般の手続きの時期案内に使う項目であり、新しい税務判定の必須条件にはしない。
- 正常に実績0件：申告済みの実績がある場合だけ登録する旨を明示し、新規実績の決算日欄へ。未申告や税務上の問題なしとは断定しない。
- 直近決算期の申告日がnull：その決算日を表示し、その実績IDの申告日欄へ。行のID順ではなく、既存評価器と同じ決算期末日の比較で直近を選ぶ。
- 既存チェックの検証範囲より前：同じ既存定数を用いて対象外と説明し、登録情報の確認へ。期限や税額は算出しない。
- 申告日まで登録済み：登録した日付と情報の確認先を表示。税務上の問題なし/評価済み/実行可能との保証にはしない。

会社本体は既存の厳格な読み取りで確認し、取得不可なら件数・案内・実行を表示しない。プロフィール・所在地・実績の取得失敗/通信例外/不正応答/重複/他社行は、既存の実行用loaderで拒否する。入力案内を出さず、詳細を閉じた状態でもエラー・再読み込みを表示し、その状態では新規実行も停止する。既存の確認結果は、会社本体を取得できている場合に独立して表示する。取得失敗を未登録/空/金額0に置き換えない。実績は実取得件数でページを進め、正常0件まで確認する。

## 入力欄への移動

プロフィールの既存アンカーを使用する。決算実績は `entry=new&field=fiscalYearEndDate` または `entry=実績ID&field=filedDate` の限定した組み合わせだけ受け付ける。表示先で同じ会社の実績を再取得し、登録/編集フォームを開いて入力欄へフォーカスする。別会社/不明IDはその会社の取得済み行に存在しなければ開かず、新規登録にも置き換えない。既存値をそのまま読み込む。

URLから保存・削除・チェック実行は行わない。保存結果不明・記録取得不可・処理中の既存停止条件を維持し、未確認の保存がある場合は直接リンクからも編集/フォーカスしない。通常の一覧表示・新規/編集・キャンセルは維持する。
