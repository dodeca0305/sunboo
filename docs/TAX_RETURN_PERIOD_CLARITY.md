# 決算実績の年度選択・対象期間表示

2026-11-05。main 5d2f07e（PR #162）と段階別点検記録を照合し、未対応の利用者指摘F01/F03だけを対象とする。

## 操作と互換性

- 対象年度は「決算日の年」の選択式。2025年4月〜2026年3月の実績は2026年を選ぶ。候補は現在年の100年前〜5年後、既存の選択済み年が範囲外でも残す。
- 選択年と決算日が一致する場合に従来の保存列へ `2026年3月期` を保存。年が異なる場合は利用者が修正するまで送信しない。年度選択で日付・金額・税務条件を変更しない。
- 従来の任意表記は選択肢として保持し、明示的な年の選び直しまで置換しない。既存レコードの一括変換なし。
- 登録済みカードは決算日から対象決算期を示し、開始日〜決算日と登録時の表記を併記。フォームも実際の入力期間を表示する。開始日未入力を自動的に1年前などへ置換しない。短期決算/決算期変更も実際の開始・終了日を使う。
- 管理画面とlocalStorage版の共用入力/カードを更新。ロードマップ等の税務判定・期限計算・保存API・結果不明時の確認手順は変更しない。

## 検証

`npm test`、`npm run lint`、`npm run build -- --webpack`（ローカル）、`npm run build`（CI）、`npm run test:e2e:tax-period`、`npm run test:e2e:tax-return-safety`、`npm run test:e2e:initial-trial-flow`。

合成データで跨年、短期/閏日/開始日未入力、年度不一致の送信停止、従来表記保持、null/0の分離、正常保存、保存拒否、応答喪失後の再読込と結果確認、取得障害と復旧、正常空、375px幅、localStorage版を確認する。既存の障害試験と登録→プロフィール→決算実績→対応状況→共有の通し試験も実施する。該当2試験は古い実認証ファイルを読み込まず、合成認証/架空APIだけで完結するよう更新。

本番は架空会社23の読み取りのみ。追加/編集フォームは保存せず表示確認し、業務書き込み・リンク発行/失効・税務実行なし。CI/配信の最終結果はPRとBusiness側引き継ぎの完了記録に残す。

## 復旧と残課題

DB変更・権限変更・新規課金なし。復旧は当PRの画面/表示ヘルパーをrevertして通常配信し、保存済みデータは変更しない。新しく選択して保存した年度表記も旧画面の自由入力で扱える。

ホームの今日やること/サイドバー、書類の対象期/取得時期は未着手。横断分析・書類整理連携は次期計画のみ。決算日・開始日の入力を自動化する機能や、過去の任意表記の意味を推測して移行する処理は追加しない。
