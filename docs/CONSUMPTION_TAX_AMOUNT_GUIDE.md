# 消費税額の入力元を示す案内

2026-11-10。利用者が法人税の見本を肯定し、消費税にも同じ案内を付ける提案へ「うん」と回答。既存AmountFieldの任意helpを使い、管理用/ローカル保存用の確定消費税額へ「どこを見る？」を追加する。法人税の案内は維持する。

## 案内と根拠

既存設計はconsumptionTaxAmountを翌期中間申告回数の目安に使用する。国税庁No.6609で、基準となる年税額に地方消費税額を含めないことを確認。実際の第一表の上側にある差引税額と、中間納付税額・納付税額・地方消費税の計算・国税/地方税の合計が別欄であることを、一般用・簡易課税用の空様式を描画して確認した。

- [国税庁No.6609](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6609.htm)
- [一般用・第一表の原本](https://www.nta.go.jp/law/tsutatsu/kobetsu/kansetsu/951225/pdf/youshiki_003.pdf)
- [簡易課税用・第一表の原本](https://www.nta.go.jp/law/tsutatsu/kobetsu/kansetsu/951225/pdf/youshiki_008.pdf)
- [年度別等の様式一覧](https://www.nta.go.jp/law/tsutatsu/kobetsu/kansetsu/951225/01.htm)

見本は令和5年10月以後終了課税期間用の公開空様式。public/guides/consumption-tax-return-{general,simplified}.png（各1061×1500）へそのまま描画し、CSSで左4.3%・上57.3%・幅52.6%・高さ2.1%の対象行を示す。元の様式・年度差はキャプションで明記する。様式更新時は原本・画像・枠の位置・文言をセットで再確認する。

画面で選ばれた既存の課税方式に応じて見本と原本リンクだけを切り替える。正常未登録（null）の場合は方式を決めつけず、一般用/簡易課税用の見本をそれぞれ開いて確認できるようにする。この見本選択は課税方式の入力値を変更しない。課税方式の正しさや申告義務を判定せず、課税期間から様式を自動確定しない。不明なら推測せず税理士へ確認する案内を付ける。税額を自動転記・推定・保存しない。

## 検証と復旧

合成データで管理用/ローカル保存用の初期折り畳み、キーボード開閉、両方式の画像/公式リンク、375px、開閉前後の金額/書込回数不変を確認。法人税案内の回帰、既存表記・0/null・年度不一致・短期決算・取得失敗/復旧・保存拒否・応答喪失後の再読込/再取得も成功。合成書込3件、本番呼出/ブラウザー例外0件。Lintエラー0/既存警告1。ビルド/CI/本番の確定結果はBusiness側記録に追記する。本番は架空会社23で閲覧と案内開閉だけを行う。

初回型検査で課税方式nullの扱い不足を検出し、上記の未登録専用の見本選択に修正。入れ子の開閉に合わせて試験セレクタを対象のsummaryへ限定した後、未登録時の両見本・選択済みの両方式・ローカル保存用の未登録を含めて再検証し成功した。

入力・保存・税務判定・期限計算・DB/関数/権限/課金変更なし。復旧はこの表示変更を戻して通常配信し、DB作業は不要。

## 残課題

利用者による消費税の見本の理解度確認、異なる時期の見本追加、課税売上高など他の入力元案内は未完了。既知の広範囲画面試験の安定性と書類開閉前の選択欄要求も未解決のまま。横断分析/書類整理連携は次期計画のみで、新たな税務判定を追加しない。
