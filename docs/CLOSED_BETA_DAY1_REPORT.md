## 6. 発見事項

### 6-1. 期限警告と「今日やること」の矛盾

役員変更登記が期限超過として表示される一方、Dashboardに次の文言が表示された。

```text
直近で対応が必要な手続きはありません。安心して本業に集中してください。
```

期限超過がある場合の「今日やること」判定または文言を確認する必要がある。

### 6-2. 通知センター区画を確認できない

チェックリストはDashboardに独立した「通知センター」を想定しているが、今回の画面では確認できなかった。実装・文書・名称の整合確認が必要。

### 6-3. 役員変更登記の期限が不自然

設立日`2025-04-01`の会社に、役員変更登記の期限`2025-04-15`が表示され、期限超過となった。役員任期満了・就任・退任等の条件との整合確認が必要。

### 6-4. ステータス表記の不一致

βチェックリストの一部に「対応中」とあるが、実画面は「進行中」。文書を実画面へ合わせる必要がある。
