# 会社ホームと会社内サイドバー（H01/H02）

2026-11-05。最新main19054fb（PR #163）・段階別点検記録と進行中PRなしを確認。利用者の「行こう」を受け、試用で挙がったホームの簡素化と「今日やること」の位置を改善する。

## 表示変更

- 会社内の8画面（ホーム/会社プロフィール/決算実績/売上目標/年間ロードマップ/書類/税務レビュー/共有）を既存管理画面のサイドバーへ集約。会社IDは現在URLから取り、別会社へ移動した際に古い会社のリンクを残さない。新たな会社情報取得や権限判定は追加しない。
- 各画面上部の重複メニューとホーム末尾の重複リンクカードを削除。会社画面では管理者用メニューを展開式で残し、顧問先一覧へ戻るリンクも維持。会社外の管理画面では従来の管理メニューを表示。
- ホームは取得エラーの案内に続いて「今日やること」を先頭に配置し、理由/担当/期限/完了条件/対応先の既存表示を保持。次の期限や件数より先に行動を表示する。
- 登録情報/今月の数値・今日の売上行動・税務チェック概要と、詳しい進捗/案内は展開して確認できる。取得エラー時は登録情報を開いて、取得済み/取得できない情報を区別する。
- 「確認が必要なこと」は取得済み件数を見出しに表示。既存の重要度highがあれば最初から展開し、重要な注意を隠さない。判定基準/優先順位/期限計算は変更しない。
- スマホは既存メニューボタンの中に同じ会社内メニューを表示。選択後に閉じる。Escapeで閉じ、キーボード移動をメニュー内に保つ。

## 検証と本番の制限

全テスト/リンター/ビルド、合成画面試験、既存のホーム取得障害・復旧・正常0件/未登録・ロードマップ/書類/共有の回帰を確認する。合成画面では8遷移/選択状態/会社切替/折りたたみ内情報保持/スマホ幅/メニューのキーボード操作/エラーの可視性を確認。該当既存試験は古い実認証を読み込まず、合成認証と架空APIへ置換して本番通信を遮断した。

本番は架空会社23のホームと会社内メニューの読み取りのみ。業務保存/削除・共有発行/失効・公開共有URLへのアクセス・税務実行は行わない。DB構造/関数/権限・新規課金変更なし。CI/配信/本番確認の最終値は当PRチェックとBusiness側引き継ぎの完了記録へ残す。

## 復旧と残課題

画面変更のrevertと通常再配信で戻す。DBや保存済みデータの修復・移行は不要。試用環境の合成会社/入力は保持、書き込み停止を維持する。

書類の対象期/取得時期は次の残課題。ホーム改善への利用者の新たな評価は未受領。横断分析・書類整理連携は次期計画のみで新機能を追加しない。
