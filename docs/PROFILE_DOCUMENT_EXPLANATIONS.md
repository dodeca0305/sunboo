# 人数・役員変更日・書類の時期の説明（2026-11-06）

main b2a954a/PR #168・169と点検記録を確認し、試用で残ったP04/P07と書類の時期表示を分けて対応する。

## 今回の表示変更

会社管理と一般プロフィールで共通の説明を表示する。

- 従業員数は会社が直接雇用する従業員の実人数として入力すること、パート/アルバイトを含めた3人＋2人＝5人の例、勤務時間による0.5人への換算をしないことを示す。
- この合計と各制度の対象人数は別と明記。0人のときも役員報酬等で必要な手続きがあり得ることを表示する。役員兼務・派遣・出向などは給与台帳/雇用契約書と担当専門家へ確認する案内を追加する。
- 役員変更日は、変更が実際に効力を生じる日であり、登記申請日や締切ではないと説明。就任承諾と就任が同日である場合の例、総会の日と同じとは限らないこと、議事録/承諾書の確認、未定なら空欄で保存可能を示す。

人数の定義の参考は[労働局のパート等を含む人数の説明](https://jsite.mhlw.go.jp/hiroshima-roudoukyoku/hourei_seido_tetsuzuki/roudoukijun_keiyaku/shugyoukisoku/shugyoukisoku_point01_02.html)、制度ごとの区別は[日本年金機構](https://www.nenkin.go.jp/service/kounen/tekiyo/jigyosho/20150518.html)、就任日と決議日の違いは[法務局Q＆A](https://houmukyoku.moj.go.jp/homu/static/shougyou.html)で確認した。労働局の事業場単位の就業規則要件を、会社全体の人数だけで自動判定する変更ではない。

## 書類の時期

現行DBは状態と状態更新日時だけで、対象期間・発行日を持たない。そのため「今年提出した書類」を「会社の書類」へ変更し、登録済み/要更新の行には対象期間、発行日、作成・変更日が未記録と表示する。今年分・最新版・提出済みと保証せず、原本の確認を促す。状態更新日時や別の決算実績から書類の対象時期を推測しない。

今後必要な書類の準備状況も書類名単位の共通記録で、年度別の提出済み記録ではないと明記。状態を変える処理・保存payload・取得失敗時の停止・応答喪失後の再取得は変更しない。

実際の時期を入力・保持するにはDB変更が必要。限定案は[DOCUMENT_TIMING_DB_PROPOSAL.md](DOCUMENT_TIMING_DB_PROPOSAL.md)にまとめた。既存表に任意日付3列と期間CHECK1つの追加案だけで、未承認・未適用。今回のPRは表示と提案までで、書類の時期を保存できるようになったとは扱わない。
