# 売上目標データの取得失敗時の保護（2026-10-31）

## 選定

- 開始時の最新mainはPR #139反映済みの `0d94b5a`。未解決Issueを検索し、0件であることを確認した。
- 本番のトップ・会社情報入力・会社ホーム・売上目標・年間ロードマップ・書類・共有・税務レビューを読み取り専用で確認。会社別の確認は実データのない専用会社ID 23のみ。
- 売上目標画面のコードは4種類のSELECTでerrorを確認せず、失敗時のnullを空配列へ変換していた。これにより登録済みデータを取得できていないのに未登録のドラフトが表示され、月次・週次・日次のupsertで既存値を空欄・0で上書きするおそれがあった。納税予定取得の失敗も0件と扱われた。
- 既存値の保護を優先し、この不具合1件を今回の対象とした。旧動作で実データを上書きする再現は行っていない。

## 変更

- 既存の取得・変換処理を `loadWorkspaceGrowthData` へ移動。会社IDの絞り込み、取得列、既存の値変換を維持し、4クエリを並列実行する。
- いずれかがerror・nullデータ・通信例外となった場合は明示的なunavailable状態を返し、フォームの代わりに取得失敗の案内と再読み込みリンクを表示する。
- この状態では金額や行動計画を未登録・0として表示せず、編集・保存・実行計画作成の操作を表示しない。
- 正常に取得した空配列は未登録として扱い、従来どおり入力できる。
- DBスキーマ・権限・保存処理・既存データの変更なし。
